# Circular Studios Steam branding pack

## Upload files

- `steam_creator_logo_184x184.png` — Steam Developer/Publisher Creator Homepage square logo.
- `steam_community_avatar_184x184.jpg` — Steam Community group avatar.
- `steam_creator_header_1500x220.jpg` — Creator Homepage header (recommended upload copy).
- `steam_creator_header_1500x220.png` — Lossless header alternative.

## Reusable masters

- `circular_studios_mark_master_2048.png` — transparent studio mark.
- `circular_studios_wordmark_master_2048x512.png` — transparent wordmark.
- `circular_studios_avatar_512x512.png` — high-resolution social/community avatar.
- `circular_studios_brand_preview_1500x844.png` — identity preview, not an upload requirement.

## Palette

- Night: `#070A0F`
- Ice: `#DFF7FF`
- Cyan: `#4FC3DC`
- Cyan shadow: `#176780`
- Gold: `#F0D17D`

Regenerate the pack from the repository root with:

```powershell
python 'Tools\generate_circular_studios_branding.py'
```
